# surfReport

App personal de reporte de surf para Lima, Perú. Recomienda a qué playa ir según
las condiciones y **según el nivel de cada surfista** — lo que es un buen día
para un surfista avanzado es exactamente lo que hay que evitar con un niño que
recién aprende.
